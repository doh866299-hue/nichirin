# 鬼灭 · 日轮呼吸法 (Nichirin Breathing)

一款面向 **Minecraft 26.3 (NeoForge)** 的零前置独立《鬼灭之刃》呼吸法模组，现已完整实装 **水之呼吸 · 全十一型** 与 **日之呼吸（火之神神乐）· 全十三型** 双独立日轮刀体系，包含浮世绘风格 3D 刀光与雕琢水龙/太阳神龙特效、炽红赫刀动态显现、第一/第三人称连贯挥刀编舞及高帧率战斗物理反馈。

> **声明 / 免责提示**：本模组的代码、贴图与特效实现几乎完全由 AI 辅助完成，属于个人兴致驱动的自用作品，**仅供娱乐与交流学习**。不保证数值平衡、代码规范、多模组兼容性及后续持续更新，游玩前建议自行备份存档。

## 核心特性

- **双独立日轮刀流派**：
  - **水之日轮刀**（深海蓝刃）：铭刻原版 **水之呼吸 · 全十一型**（含空中/侧移自动变式「横水车」「雫波纹突刺·曲」与长按 1→4 圈回旋叠势化龙的「生生流转」）。
  - **日之日轮刀**（漆黑刃身，全集中 / 第十三型圆环 / 奥义爆发自动烧红化作**炽红赫刀**）：铭刻漫画第 192 话正统圆环顺序的 **日之呼吸 · 火之神神乐全十三型**，包含「灼骨」-75% 禁疗、亡灵克制、3D 虹光残像「幻日虹」、7.4 格破盾穿甲「飞轮阳炎」、4 段多目标游龙穿锁「日晕之龙·头舞」以及 1→12 无限循环连舞的「**第十三型 · 日之圆环**」。
- **浮世绘 3D 特效与雕琢神龙**：自研浮世绘浪纹/黑红烈焰 3D 刀光带、立体冲击环、瀑布/炎瀑水幕及全 3D 东方神龙（鹿角龙须、鳞腹分层纹理与无闪烁赛璐璐描边）。
- **直觉化战斗反馈**：全集中呼吸、「隙之线」破绽洞察与斩断、高刷丝滑插值、怪物受击布娃娃物理、零地形破坏的环境碎屑与水火元素互动（水灭火/高空水垫缓震、火烤生肉/蒸腾白汽）。
- **零前置依赖**：单 JAR 即可运行，支持单人与联机（联机时客户端与服务端均需安装）。

## 按键操作

手持**水之日轮刀**或**日之日轮刀**时生效（自动切换对应流派与 HUD 主题，可在按键设置「鬼灭 · 呼吸法」中自由改键）：

| 按键 | 功能 |
| --- | --- |
| `Shift + 鼠标滚轮` 或 `Z` / `C` | 切换上一 / 下一剑型（水呼、日呼各自独立记忆选招位置） |
| `右键` | 立即施放当前选中的剑型 |
| `长按右键`（水·拾之型「生生流转」） | 连续回旋突进叠势（1 → 4 圈化龙加速增伤），松手或满 4 圈自动接断首终结斩 |
| `点按 / 长按右键`（日·第十三型「日之圆环」） | 自动按 `1.圆舞 → … → 12.炎舞 → 1.圆舞` 高速无缝无限连舞，并燃起炽红赫刀 |
| `R`（短按 / 长按） | 短按切换「全集中·常中」（日呼点燃炽红赫刀）；长按原地深呼吸蓄气 |
| `G` | 开关当前流派的全剑型速查目录 |

| 陆之型 | **扭转漩涡** | 贴身高速旋涡绞杀并摧毁来袭弹射物，**水中 / 雨天**大幅强化 |
| 柒之型 | **雫波纹突刺** / **曲** | 极速穿刺并绽放 3D 同心水波纹；**侧移 / 潜行 / 空中**自动转为曲刺 |

## 日之呼吸 · 火之神神乐全十三型一览（手持「日之日轮刀」）

采用漫画第 192 话「廻る縁」正统圆环顺序：

| 顺位 | 名称 | 特点与专属机制 |
| :-: | --- | --- |
| 1 | **圆舞** / **圆舞一闪** | 大弧烈焰重斩；**疾跑 / 潜行**施放自动触发雷步衍生技「**圆舞一闪**」 |
| 2 | **碧罗之天** | 由下而上 360° 垂直升天大炎轮挑斩，强力挑空且对空中目标增伤 |
| 3 | **烈日红镜** | 左右「∞」字高速交叉双弧火焰斩，攻防一体焚灭周身弹射物 |
| 4 | **幻日虹** | 高速位移闪避并在原地留下 **3D 炽热虹光残像** 诱敌反灼，受击触发完美闪避炽炎反杀 |
| 5 | **火车** | 凌空跃起前空翻绕越敌方上方，顺下坠之势纵轮炎劈 |
| 6 | **灼骨炎阳** | 螺旋焚骨炎涡多段绞杀，命中附加长达 6.5 秒的「灼骨」-75% 禁疗 |
| 7 | **阳华突** | 极速直线贯刺，刺点绽放 3 层立体炽金太阳日冕环 |
| 8 | **飞轮阳炎** | 7.4 格超远扭曲阳炎延伸斩，直接破盾并附加 30% 穿甲灼热直伤 |
| 9 | **斜阳转身** | 半空 180° 倒立逆转身体，自上而下挥出猛烈奇袭横斩 |
| 10 | **辉辉恩光** | 凌空螺旋俯冲倾泻太阳炎瀑，伤害随实际下落高度加成 |
| 11 | **日晕之龙·头舞** | 召唤 3D 太阳神龙绕身咆哮，4 段高速游龙智能穿锁周围多个目标，终段爆开日轮热浪 |
| 12 | **炎舞** | 重斩接回旋炽炎暴劈强力二连击，动作自然闭环衔接回第 1 型「圆舞」 |
| 13 | **第十三型 · 日之圆环** | 选中后**点按或长按右键**将 1→12 型无缝无限循环连舞，自动燃起赫刀、耗气递减、增伤叠加，满 12 招触发「破晓圆环」强力回气 |

## 生存获取方式

1. **猩猩绯砂铁 ×2**：工作台使用 `红石`、`铁锭 ×2`、`下界石英`、`青金石` 合成（菱形摆放，石英居中）。
2. **猩猩绯玉钢 ×1**：工作台使用 `猩猩绯砂铁 ×4` 环绕 `钻石 ×1` 合成。
3. **水之日轮刀 ×1**：工作台使用 `猩猩绯玉钢 ×2`、`青金石块 ×2` 与 `木棍 ×1` 斜向锻造而成。
4. **日之日轮刀 ×1**：工作台使用 `猩猩绯玉钢 ×2`、`金块 ×2` 与 `烈焰棒 ×1` 斜向锻造而成。

> 创造模式可在专属物品栏 **「鬼灭 · 日轮呼吸法」** 中直接获取。

## 安装与构建

### 直接游玩
1. 安装对应版本的 **Minecraft 26.3 + NeoForge**。
2. 从本仓库的 [Releases](../../releases) 页面下载最新版 `nichirin-x.x.x.jar`。
3. 将 `.jar` 放入 `.minecraft/mods/` 目录后启动游戏即可（更新版本时请移除旧版 JAR）。

### 从源码编译
需要安装 **JDK 25**：

```powershell
# Windows (PowerShell)
.\gradlew.bat build
```

```bash
# Linux / macOS
./gradlew build
```

编译产物位于 `build/libs/nichirin-1.1.0.jar`。
