# 鬼灭 · 日轮呼吸法 (Nichirin Breathing)

一款面向 **Minecraft 26.3 (NeoForge)** 的零前置独立《鬼灭之刃》呼吸法模组，主打原版 **水之呼吸 · 全十一型** 剑技还原、浮世绘风格 3D 刀光与雕琢水龙特效、第一/第三人称连贯挥刀编舞及高帧率战斗物理反馈。

> [!NOTE]
> **声明 / 免责提示**：本模组的代码、贴图与特效实现几乎完全由 AI 辅助完成，属于个人兴致驱动的自用作品，**仅供娱乐与交流学习**。不保证数值平衡、代码规范、多模组兼容性及后续持续更新，游玩前建议自行备份存档。

---

## 核心特性

- **原版水之呼吸 · 全十一型还原**：从壹之型「水面斩」到拾壹之型「凪」，涵盖空中/侧移自动变式（贰之型·改「横水车」、柒之型·曲「雫波纹突刺·曲」），以及长按回旋叠势化龙的拾之型「生生流转」。
- **浮世绘 3D 水流与雕琢水龙**：自研 3D 浮世绘浪纹刀光、立体水波纹、瀑布水幕与全 3D 东方水龙模型（带鹿角龙须、鳞腹分层纹理与无闪烁赛璐璐描边）。
- **直觉化物理与反馈**：
  - **全集中呼吸**：短按切换常中增益，长按深呼吸快速蓄气。
  - **隙之线**：洞察破绽并触发精准处决加成（配合伍之型「乾天的慈雨」可触发慈悲处决与回气）。
  - **高帧率战斗演出**：支持高刷丝滑插值、怪物受击布娃娃物理与零地形破坏的环境碎屑飞溅。
- **零前置依赖**：单 JAR 即可运行，支持单人与联机（联机时客户端与服务端均需安装）。

## 按键操作

手持**日轮刀**时生效（可在游戏内按键设置「鬼灭 · 呼吸法」中自由改键）：

| 按键 | 功能 |
| --- | --- |
| `Shift + 鼠标滚轮` 或 `Z` / `C` | 切换上一 / 下一剑型 |
| `右键` | 立即施放当前选中的剑型 |
| `长按右键`（选中拾之型·生生流转时） | 连续回旋突进叠势（1 → 4 圈化龙加速增伤），松手或满 4 圈自动接断首终结斩 |
| `R`（短按 / 长按） | 短按切换「全集中·常中」；长按原地深呼吸蓄气 |
| `G` | 开关界面中的「水之呼吸全十一型目录」 |

## 水之呼吸 · 全十一型一览

| 剑型 | 名称 | 特点与触发变式 |
| --- | --- | --- |
| 壹之型 | **水面斩** | 利落的水平一文字斩击与延时浪涌 |
| 贰之型 | **水车** / **改·横水车** | 地面 360° 纵翻圆斩；**空中**自动变为水平 360° 横水车 |
| 参之型 | **流流舞** | 三段 S 型蛇形流水高速掠斩 |
| 肆之型 | **打潮** | 四段海潮连绵压制斩，终段重劈掀浪 |
| 伍之型 | **乾天的慈雨** | 高弧温柔甘霖斩；对低血量或「隙之线」暴露目标触发高额慈悲处决并回复呼吸值 |
| 陆之型 | **扭转漩涡** | 贴身高速旋涡绞杀并摧毁来袭弹射物，**水中 / 雨天**大幅强化 |
| 柒之型 | **雫波纹突刺** / **曲** | 极速穿刺并绽放 3D 同心水波纹；**侧移 / 潜行 / 空中**自动转为曲刺 |
| 捌之型 | **泷壶** | 跃起垂直下劈倾泻浮世绘瀑布水幕，落地激起环形冲击水浪（高空下劈伤害更高） |
| 玖之型 | **水流飞沫·乱** | 低耗短冷却全向 WASD 点水碎步身法，可无缝衔接任意其他剑型 |
| 拾之型 | **生生流转** | 按住右键持续回旋前进（1→4 圈），水龙随圈数不断成长、移速与伤害层层叠加，松手挥出终结一斩 |
| 拾壹之型 | **凪** | 展开绝对静止水镜领域，湮灭来袭弹射物并反斩近身攻击 |

## 生存获取方式

1. **猩猩绯砂铁 ×2**：工作台使用 `红石`、`铁锭 ×2`、`下界石英`、`青金石` 合成（菱形摆放，石英居中）。
2. **猩猩绯玉钢 ×1**：工作台使用 `猩猩绯砂铁 ×4` 环绕 `钻石 ×1` 合成。
3. **日轮刀 ×1**：工作台使用 `猩猩绯玉钢 ×2`、`青金石块 ×2` 与 `木棍 ×1` 斜向锻造而成。

> 创造模式可在专属物品栏 **「鬼灭 · 日轮呼吸法」** 中直接获取。

## 安装与构建

### 直接游玩
1. 安装对应版本的 **Minecraft 26.3 + NeoForge**。
2. 从本仓库的 [Releases](../../releases) 页面下载 `nichirin-x.x.x.jar`。
3. 将 `.jar` 放入 `.minecraft/mods/` 目录后启动游戏即可。

### 从源码编译
需要安装 **JDK 25**：

```powershell
# Windows (PowerShell)
.\gradlew.bat build
```

```bash
# Linux / macOS
./gradlew build
```

编译产物位于 `build/libs/nichirin-1.0.0.jar`。
